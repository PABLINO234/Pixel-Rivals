PIXEL RIVALS 2.3

NOVEDADES
- Ventana redimensionable.
- F11 activa/desactiva pantalla completa.
- Escalado proporcional, sin deformar la arena.
- Cinco diseños de arena elegidos aleatoriamente en cada nueva partida.
- Se conservan las mecánicas de la versión 2.2.

CONTROLES
- Jugador 1: WASD; dash con F.
- Jugador 2: flechas; dash con Ctrl derecho.
- Enter: jugar / nueva partida.
- Esc o Espacio: pausa / continuar.
- R: reiniciar.
- F11: pantalla completa.

EJECUTAR EN RASPBERRY PI
Desde la carpeta del proyecto:
    python3 main.py

Requiere Pygame (en Raspberry Pi OS: sudo apt install python3-pygame).
